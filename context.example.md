# Contexto

Esto lo lee el paso de revisión para poner los nombres reales, y además se usa
para sesgar el reconocimiento hacia el vocabulario propio.
Cuanto más fiel sea, mejores salen los nombres y menos errores de términos.

## Quiénes participan

- **Ana** — lidera el equipo. Reparte el trabajo y es la que más habla.
- **Bruno** — back end. Habla de la base de datos y de los endpoints.
- **Carla** — front end.
- **Diego** — QA. Reporta lo que encontró probando.

## Vocabulario

Nombres de productos, repos, siglas y jerga que aparecen seguido y que el
reconocimiento suele escribir mal:

staging, rollback, endpoint, merge, pull request, deploy, sprint, backlog

## Errores conocidos del reconocimiento

Una línea por error, "lo que escribe" → "lo que es":

- "pull rec" → pull request
- "estein" → staging
